# Flex Consistency Review Package

This ZIP contains:
- `flex-consistency-review/`: the Skill package (SKILL.md, rules, index, script, report template)
- `DESIGN.md`: the complete design document

Start with `DESIGN.md`, then install/use the `flex-consistency-review` folder as a Skill.

Important: the index is stored inside the Skill as requested. For each project, keep a separate working copy or provide a project-specific `--index` path. See `DESIGN.md` for the exact command.
